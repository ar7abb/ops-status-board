# Blueprint Changelog

This public changelog summarizes approved changes to the Ops Status Board learning and delivery plan. The detailed master blueprint and coaching records remain private control documents outside Git.

## 2.1.0 — 2026-08-02

- Established a private-control/public-portfolio documentation split.
- Kept the detailed project state, master blueprint, and raw learning log outside the public repository.
- Limited the initial public repository to concise portfolio documentation and sanitized evidence.
- Preserved the technical architecture and local-first delivery order from version 2.0.0.

## 2.0.0 — 2026-08-02

- Reordered the project so the application is built and proven locally before AWS work begins.
- Moved manual server deployment, observability, backup, restore, and recovery practice ahead of cloud adaptation.
- Deferred Ansible, AWS CLI, and Terraform installation until the milestones where each tool becomes useful.
- Preserved the approved application, container, CI/CD, observability, and cloud technology choices.

## 1.1.0 — 2026-07-31

- Established the initial resumable learning workflow and state schema.
- Defined WSL2 as the development workstation and a separate Ubuntu VM as the local practice server.
- Defined the planned FastAPI, PostgreSQL, Docker Compose, GitHub, Nginx, observability, backup, Terraform, Ansible, and AWS direction.
- Added privacy, verification, recovery, and cloud-cost gates.

## Change rule

Possible ideas belong in the backlog. An entry is added here only after a change to the approved plan has been reviewed, accepted, and assigned a blueprint version.
